# # Определение

***Гиперссылки(или ссылки)*** - это указатели на документ в сети. Для работы с ним был придуман стандарт, состоящий из трёх "столбов":
1) *URL(Uniform Resource Locator)* -  система адресации, позволяющий обращаться с веб-документами;
2) *HTTP(HyperText Transfer Protocol)* - протокол для поиска документов по его URL;
3) *HTML(HyperText Markup Language)* - язык разметки, поддерживающий внедрение гиперссылок.

В целом, концепция веб-сайтов напоминает UNIX-системы. Первые построены на документах, вторые же - на файлах. Но по факту, навигация по сайту и есть файловая система: **маршрут на сайте = путь в файловой системе**.

Гиперссылки удобны тем, что позволяют пользователю проще ориентироваться и комфортно перемещаться по сайту. Тяжело каждый раз в адресной строке писать длинный URL для доступа к маршруту, где находится важная информация. Так, эта концепция сделала интернет простым и интуитивно понятным в использовании.

#  # Типы ссылок

1) Internal links - это ссылки внутри одного веб-ресурса(сайта). Они встречаются чаще всего, т.к. нужны для быстрой навигации.
2) External links - это ссылки на внешний ресурс.
3) Incoming links - это ссылка со внешнего ресурса на твой сайт.
4) Anchors(якорь) - это ссылка для навигации внутри документа.

*Интересный факт: гиперссылки используются поисковым движком для определения релевантности ресурса для конкретных запросов. То есть чем больше incoming links, тем выше будет ресурс в поисковике.*
